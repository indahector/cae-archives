AE Data Quality Guidance

What the Cal-Adapt downscaled data is, how good it is, and what it can be used for

Published

November 12, 2026

This site characterizes the Cal-Adapt Analytics Engine downscaled climate data (WRF and LOCA2) variable by variable, and states plainly what each is good for.

It is produced by the Data Quality & Documentation Pillar, and its guiding principle is:

Document, don’t fix. This pillar characterizes the data and discloses what is known. Where a question is open, the deliverable is a clear statement of the issue and its likely cause, not its resolution.

Variables covered

variable status headline
Wind speed complete, in review Unbiased at well-sited stations; distribution too narrow, so power density is under-predicted by 13–19 % and high-wind days by a factor of four
Relative humidity complete The verdict splits by product. WRF-ERA5 is usable for fire weather; LOCA2 finds a third of the critical days and no simple correction repairs it

Temperature, precipitation and snow are candidates for the next pass.

Alongside the variables, the catalog audit characterizes the archive’s metadata: 1,961 findings across 390 datasets, 276 of them errors, and two codes on WRF’s wind components account for 208.

How to use this site

If you want a recommendation for an specific case → the recommendation matrix. Good-for, use-with-caution, or not-recommended, per variable × use case, with the evidence behind each.

If you have a variable name in hand and want to know what it is → the variable cards. One card per variable: definition, source, transformations, known issues.

If you want to know what happened to a variable before it reached you → the provenance flowchart. The plain-language path from global model to delivered value, with the known gaps marked.

If you want to know whether the catalog itself is sound → the catalog audit. Metadata quality across the whole cadcat archive, checked through two independent access paths, because a requirement can fail in the published store and pass in what users receive, or the reverse.

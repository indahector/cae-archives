Provenance

What happened to a value before it reached you

Published

November 12, 2026

The plain-language path from raw global model to the number a user pulls from the platform. Every variable gets the same diagram with its own stages and its own gaps, and only the variable-specific branches and gap nodes change.

How to read it. Amber stages are where this pillar’s documentation attaches, the bias-correction steps and AE-side processing. Red nodes are known gaps/issues we disclose rather than fix. An arrow not explicitly labeled is a documentation hole to chase.

The shared backbone

Every variable follows the same five stages:

  1. Global climate model: CMIP6, SSP3-7.0
  2. Bias correction: differs by path. A priori on the GCM boundary conditions for WRF (some runs only), quantile-preserving and observation-trained for LOCA2
  3. Downscaling: dynamical (WRF, 3 km, hourly) or statistical/hybrid (LOCA2, 3 km)
  4. Cataloguing: cadcat, analysis-ready
  5. AE-side processing : derived variables, indices, localization

What changes per variable is which variables each path publishes, what is derived rather than native, and which gaps attach where.

Wind

What the wind diagram exposes

  • The bias-correction ambiguity (amber → red). The WRF a priori bias correction exists for some runs and not others, and AE appears to serve the non-a-priori-BC WRF (R19 run matrix; Q02 App. A). Resolving which cadcat runs are which is the first bias-adjustment documentation task — and if the answer is inconsistent across simulations, that is itself a data-quality finding.
  • LOCA2 wind parity (R02). The hybrid path produces a wind field, but wind is not statistically downscaled the way temperature and precipitation are. This becomes the “use-with-caution” basis for every LOCA2 wind row in the matrix.
  • The wspeed discrepancy (DQ4). wspeed does not reconcile with the components in the LOCA2 hybrid files. Wind speed is downscaled independently rather than derived from the components. wspeed variable card.

Sources: R02, R09, R12, R15, R16, R19, Q01, Q02, Q03; open question DQ4. Full entries on the References page.
